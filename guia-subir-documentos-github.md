# Guía sencilla: cómo subir documentos a GitHub

**Objetivo:** crear un repositorio, subir un documento Markdown (`.md`) y compartirlo mediante un enlace, sin utilizar la terminal ni escribir código.

## 1. ¿Qué es GitHub?

GitHub es una plataforma donde podemos guardar archivos, organizarlos en proyectos y compartirlos con otras personas. Un **repositorio** es una carpeta de proyecto en GitHub que también conserva un historial de cambios.

Un archivo **Markdown** (`.md`) es un documento de texto que permite usar títulos, listas, enlaces y otros formatos sencillos. GitHub lo muestra de forma legible automáticamente.

## 2. Crear un repositorio nuevo

1. Entra en [github.com](https://github.com) e inicia sesión.
2. Abre [github.com/new](https://github.com/new), o pulsa el símbolo **+** y elige **New repository**.
3. En **Owner**, comprueba que aparece tu cuenta.
4. En **Repository name**, escribe, por ejemplo, `mi-primer-repositorio-md`.
5. En **Description** (opcional), pon `Prueba para aprender a compartir documentos Markdown`.
6. En **Visibility**, selecciona **Public** si quieres que cualquiera pueda leer el contenido. Si es información privada, selecciona **Private**.
7. Activa **Add a README file** para crear una página de presentación del repositorio.
8. Deja el resto de opciones como están y pulsa **Create repository**.

> **Importante:** en un repositorio público, cualquier persona en Internet puede leer los archivos. No subas contraseñas, información personal ni documentos confidenciales.

## 3. Subir un documento Markdown

1. Entra en el repositorio que acabas de crear.
2. Encima de la lista de archivos, pulsa **Add file** → **Upload files**.
3. Arrastra el archivo `.md` desde tu ordenador o pulsa **choose your files** para seleccionarlo.
4. Comprueba que aparece el nombre del archivo en la página.
5. Escribe un mensaje descriptivo, por ejemplo: `Añadir guía Markdown`.
6. Confirma la subida con **Commit changes** (en algunas pantallas puede aparecer **Propose changes** y requerir un paso adicional).
7. Regresa a la lista de archivos del repositorio y comprueba que está el documento.

**Nota:** un *commit* es un registro de un cambio realizado en el repositorio.

## 4. Ver el documento en GitHub

1. Haz clic en el nombre del archivo `.md` dentro del repositorio.
2. GitHub mostrará el contenido con los títulos y las listas formateados.
3. Si quieres ver el texto original de Markdown, utiliza las opciones de visualización de la página.

## 5. Compartir el enlace

- **Compartir el repositorio:** abre su página principal, copia la dirección de la barra del navegador y envíala.
- **Compartir solo el documento:** abre el archivo `.md`, copia la dirección de la barra del navegador y envíala.
- En un repositorio **Public**, quien reciba el enlace podrá leerlo sin que tengas que darle permiso.
- En un repositorio **Private**, el enlace por sí solo no da acceso: tendrás que invitar a esa persona con los permisos adecuados.

## 6. Modificar el documento más adelante

1. Abre el documento dentro de GitHub.
2. Usa la opción de edición (icono del lápiz, cuando esté disponible).
3. Realiza los cambios.
4. Guarda los cambios mediante **Commit changes**.

También puedes modificar el archivo en tu ordenador y subir la nueva versión al repositorio, confirmando el cambio cuando GitHub te lo solicite.

## 7. Recordatorio rápido

**Crear repositorio → Subir archivo `.md` → Confirmar cambios → Abrir documento → Copiar enlace → Compartir.**
